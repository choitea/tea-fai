# 티키피디아(Teakipedia) — 차 백과 & 우림 타이머

《찻잎의 시간, 오늘의 한 잔》과 《최초의 가향 홍차 — 얼그레이의 모든 것》에 실린
산화도·제다·향미·페어링·우림 수치를 바탕으로, 중국 6대 다류와 10대 명차, 스리랑카·인도·네팔·케냐·일본·대만·한국의 대표 차, 그리고 대용차·허브차·블렌딩차·과일차까지 93종을 담은 안드로이드용 PWA입니다.
10문항으로 93종 중 나에게 맞는 차를 골라 주는 「나에게 맞는 차 찾기」 취향 테스트가 들어 있습니다.
한국어 · English · 简体中文 · 繁體中文 네 언어를 지원합니다.

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 앱 본체 (화면 뼈대 + 아이콘 스프라이트) |
| `styles.css` | 찻집 에디토리얼 스타일 (배경 `#F7F3EB`, 찻잎 그린 `#243E32`, 앰버 `#B97A3D`) |
| `data.js` | 차 계열 10종 · 품종 93종 데이터(한/영/중간/중번) · 기분별 추천 · 취향 태그 · 링크 |
| `app.js` | 탭 전환, 우림 타이머, 차 백과, 시음 노트(localStorage), 10문항 취향 테스트, 언어 전환, 파트너 티룸·추천 연결 |
| `i18n.js` | 한국어·English·简体中文·繁體中文 문구 사전(퀴즈 10문항 포함)과 언어 감지 |

| `data/affiliate.json` | 추천 찻잎·다구 둘러보기, 전자책, 유튜브 채널 연결 (쿠팡파트너스 숏링크 발급 전에는 검색 링크로 안내) |
| `manifest.webmanifest` | PWA 설치 정보 (이름·아이콘·테마 색) |
| `sw.js` | 오프라인 캐시 — 앱 껍데기는 네트워크 우선, `data/`는 stale-while-revalidate (캐시 `teafai-v6`) |
| `privacy.html` | 개인정보처리방침 (회원가입·서버 전송 없음, 기기 저장소에만 보관) |
| `icons/icon-192.png`, `icons/icon-512.png`, `icons/icon-maskable-512.png` | 홈 화면 아이콘 |
| `tea_fai_app_standalone.html` | CSS/JS를 모두 인라인한 단일 파일 (파일로 바로 열기) |
| `preview_home.png` · `preview_timer.png` · `preview_guide.png` · `preview_notes.png` | 390×844 화면 캡처 |
| `build_standalone.py` | `index.html` + CSS + JS → 단일 파일 재생성 |
| `make_icons.py` | 아이콘 재생성 |

## 바로 열기

- **웹에서 바로 쓰기 (설치 없이)**: <https://choitea.github.io/tea-fai/>
  - 폰 브라우저에서 주소를 열고 메뉴 → **홈 화면에 추가**를 누르면 주소창 없는 앱으로 설치됩니다.
  - 개인정보처리방침: <https://choitea.github.io/tea-fai/privacy.html>
- **단일 파일**: `tea_fai_app_standalone.html`을 브라우저로 열면 끝 (인터넷 없이도 동작).
- **앱처럼 설치**: 아래처럼 로컬 서버를 띄운 뒤 `http://<PC IP>:8000/index.html`을 폰 크롬에서 연다.
  주소창 메뉴 → **홈 화면에 추가**를 누르면 주소창 없는 앱으로 실행되고 오프라인에서도 열립니다.
- **APK 바로 설치**: <https://choitea.github.io/tea-fai/teakipedia-release.apk> (안드로이드, 1.45MB)
  폰 브라우저에서 내려받아 열면 "출처를 알 수 없는 앱 설치" 확인을 한 번 거쳐 설치됩니다.

  ```bash
  cd tea_fai_app
  python3 -m http.server 8000
  ```

  폰과 PC가 같은 와이파이에 있어야 합니다. 웹에 올릴 때는 폴더째 HTTPS 도메인에 두면 됩니다
  (서비스 워커는 HTTPS 또는 localhost에서만 동작).

## 파트너·추천 데이터 고치기

`data/shops.json`·`data/affiliate.json`은 앱 껍데기와 따로 갱신됩니다. JSON을 고쳐 커밋하면
서비스 워커가 stale-while-revalidate로 다음 실행부터 새 값을 쓰고, 앱을 다시 설치하거나
플레이에 새 버전을 올릴 필요가 없습니다.

- 매장 전화로 개인 휴대폰 번호를 노출하지 않습니다. 풍성한뷔페는 매장 번호 `010-5563-8272`,
  홍콩티는 네이버 플레이스 링크로 안내합니다.
- `affiliate.json`의 `items`에 쿠팡파트너스 숏링크를 넣고 `is_active: true`로 바꾸면 대가성
  문구와 함께 노출되고, 그 전에는 `browse`의 검색 링크(수수료 없음)만 보입니다.
- 가격은 발급·확인 시점 값이므로 화면에 "판매처 기준가"로 표기합니다.

## 데이터 다시 만들기

```bash
python3 build_standalone.py   # 단일 HTML 재생성 (HTML/CSS/JS 수정 후)
python3 make_icons.py         # 아이콘 재생성
```

## 검증한 것

- 390×844 모바일 뷰포트에서 4개 탭 모두 렌더링, 가로 넘침 없음, 콘솔 에러 없음
- 폰트: 언어 전환 시 `<html lang>`이 `ko`·`en`·`zh-CN`·`zh-TW`로 바뀌고, Pretendard 동적 서브셋(비동기 로드, `font-display: swap`)과 시스템 CJK 폴백을 씀. 타이머 숫자는 `tabular-nums`
- 파트너 티룸: 홈 카드에서 영업 상태(서울 시간 기준)·대표 메뉴 가격·지도/전화/플레이스, 상세에서 요일별 영업시간·메뉴·지도 3종. 취향 테스트 결과와 백과 카드에서 "이 차를 내는 찻집"·"추천 찻잎·다구"·전자책·유튜브로 연결
- 타이머: 프리셋별 기본 시간, 1·2·3포 전환, ±10초, 시작/일시정지/초기화, 완료 알림
- 차 백과: 키워드 검색, 차류 필터(6대 다류·블렌딩·대용차·허브·과일), 카드 펼침, "이 차로 타이머 맞추기"
- 취향 테스트: 10문항 진행 표시(3 / 10), 4개 언어, Best 1 + 대안 2종 추천, 결과에서 타이머·백과 연결, 다시 테스트
- 시음 노트: 저장 → 새로고침 후 유지 → 삭제
- 서비스 워커 등록 및 오프라인 재접속, 단일 파일 실행
